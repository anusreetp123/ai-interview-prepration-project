# ai-interview-prepration-project
AI Interview Preparation Coach built with Streamlit and Groq LLM. Generates role-based interview questions and evaluates candidate answers with AI-powered feedback, scoring, strengths, improvements, and interview tips.

## 📌 Features

- Generate interview questions for different job roles
- Choose Behavioral, Technical, or Mixed interview styles
- AI-powered answer evaluation
- Interview score (0–10)
- Personalized strengths and improvement suggestions
- Interview tips for better responses
- Interactive Streamlit web interface
- Fast inference using the Groq API
