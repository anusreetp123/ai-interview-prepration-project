# 🤖 AI Interview Preparation Coach

An AI-powered interview preparation application built with **Python**, **Streamlit**, and the **Groq API**. The application generates role-specific interview questions and evaluates user responses using a Large Language Model (LLM), providing personalized feedback to help candidates improve their interview skills.


## 📌 Features

- Generate interview questions for different job roles
- Choose Behavioral, Technical, or Mixed interview styles
- AI-powered answer evaluation
- Interview score (0–10)
- Personalized strengths and improvement suggestions
- Interview tips for better responses
- Interactive Streamlit web interface
- Fast inference using the Groq API

- ## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Interview-Preparation-Coach.git
```

Move into the project folder

```bash
cd AI-Interview-Preparation-Coach
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=your_api_key_here
```

Run the application

```bash
streamlit run app.py
```

## 🎯 How It Works

1. Select the interview role.
2. Choose the interview style.
3. Select the number of questions.
4. Generate AI-powered interview questions.
5. Answer each question.
6. Receive AI-generated feedback, including:
   - Interview score
   - Strengths
   - Areas for improvement
   - Model answer tips
